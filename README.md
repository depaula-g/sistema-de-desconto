# 🛒 Sistema de Desconto Progressivo

Este projeto foi desenvolvido em **Python** como uma atividade de programação. O programa calcula automaticamente o desconto de uma compra de acordo com o valor total informado pelo cliente.

## 📌 Como funciona

O programa:

1. Solicita o nome do cliente.
2. Solicita o valor total da compra.
3. Verifica qual faixa de desconto deve ser aplicada.
4. Calcula o valor do desconto.
5. Mostra o desconto e o valor final da compra.

## 💰 Regras de desconto

| Valor da compra                | Desconto |
| ------------------------------ | -------: |
| Abaixo de R$ 200               |       5% |
| De R$ 200 até abaixo de R$ 300 |      10% |
| R$ 300 ou mais                 |      15% |

## 🐍 Tecnologias utilizadas

* Python
* Estruturas condicionais `if`, `elif` e `else`
* Entrada de dados com `input()`
* Cálculos matemáticos
* Formatação de valores com `f-string`

## ▶️ Como executar

1. Tenha o **Python** instalado.
2. Abra o arquivo `app.py` no VS Code.
3. Execute o programa pelo terminal.
4. Informe seu nome e o valor da compra.
5. Confira o desconto e o total a pagar.

## 🎯 Objetivo

Praticar o uso de **estruturas de decisão em Python**, utilizando diferentes condições para definir automaticamente o desconto de uma compra.
